## Assignment（赋值）

使用 `=` 进行赋值

```
hostname = "R1"
ip = "10.1.1.1"
username = "admin"
password = "Cisco123"
```

把右边对象绑定（Bind）给左边变量。

变量名不能以数字开头

不能使用 Python 保留关键字
